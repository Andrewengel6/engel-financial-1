Launch Sequence

Day 1: Campaign 1 (Legacy Broad) + Ad Set 2 (Financial) + Ad Set 3 (Soft Protection) go live. Pixel fires. Audiences begin building.

Day 7–10: Check wizard visitor pool size in Meta. If audience > 1,000 people, launch Ad Set 1 (Retargeting). If still too small, wait until Day 14.

Day 14: First data review — CPL, cost per CompleteRegistration, contact rate. Adjust Campaign 1 creative if underperforming. Do not make structural changes yet.

Day 30: Full review across all 4 ad sets including Soft Protection. Budget reallocation decisions. Lookalike audience build if event volume qualifies.
