Tracking Setup — Launch Path Decision

The pixel is not installed. This decision determines the conversion objective and how fast we can launch.

A

Install Pixel First — Then Launch (Recommended)

Install Meta Pixel + set up custom events → launch Website Conversions campaign

Install the pixel across the site, then fire custom events at key wizard steps:

  • ViewContent — wizard page loaded
  • Lead — contact info submitted (name, phone, email)
  • CompleteRegistration — OTP verified + wizard completed

Use CompleteRegistration as the optimization event — this is your OTP-verified qualified lead. Meta optimizes for the people most likely to complete the full wizard, not just click.

Also add: Conversions API (server-side) for iOS signal resilience — your API already handles lead submissions so CAPI is a natural add-on.

Launch delay: 3–5 days to install + verify events
Quality: Maximum — full funnel tracking from day one

B

Launch Now with Meta Instant Forms — Add Pixel Later

Use Meta's native Lead Ads (no website redirect) while pixel is being set up

Meta Instant Forms open natively inside Facebook/Instagram — no website visit required. Fast load, pre-populated with user data, high completion rate.

Downsides for your use case:

  • No multi-step qualification wizard — form is flat, limited filtering
  • No OTP verification — lead quality harder to control
  • Can't A/B test your wizard flow
  • Lead data goes into Meta, not your Supabase system directly

Launch delay: Immediate
Quality: Lower — no wizard qualification, no OTP
