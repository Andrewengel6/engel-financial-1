Phase 1 — Technical Prerequisites Before Launch

  • ☐Meta Pixel installed on all pages (base code in <head>)
  • ☐ViewContent fires when wizard page loads
  • ☐Lead fires when contact info is submitted (name/phone/email step)
  • ☐CompleteRegistration fires only after OTP is verified — not before
  • ☐Conversions API (CAPI) wired to server-side lead submission endpoint
  • ☐UTM parameters captured on landing: utm_campaign, utm_adset, utm_ad, utm_content
  • ☐UTM values stored in Supabase lead record at form submission
  • ☐Meta Events Manager — verify all 3 events firing correctly before going live
  • ☐Custom conversion created in Meta: CompleteRegistration = qualified lead event
