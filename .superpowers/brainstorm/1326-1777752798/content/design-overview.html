Technical Changes

1. js/lp-wizard.js — add redirect step type
New step type: { type: 'redirect', choices: [{ label, value, icon, href }] }
On tile click: tile enters loading state → window.location.href = choice.href
2. lp/life-insurance.html — replace Q1 step config
Change step type from multiChoice → redirect. Add href to each choice. Remove all remaining steps (Q2 onwards) — no longer needed.
✓ No changes to the 6 specific LPs
whole-life.html, iul.html, annuities.html, mortgage-protection.html, retirement-planning.html, advanced-markets.html — all stay exactly as they are.

Loading State (UX detail)

When a tile is clicked, it immediately shows a spinner/pulse so the user knows their tap registered — then the redirect fires. Prevents "did my click work?" confusion on slower connections.
