## 1. Overview

This spec covers everything needed to go from creative assets to live campaign. It is structured as four sequential phases:

1. **Creative Production** — Avatar generation, Angle 1 video + static, Angles 2–4 scripts and assets
2. **Ads Manager Setup** — Campaign and ad set structure built as drafts in Meta, Angle 1 uploaded
3. **Website Pre-Launch Fixes** — Logo, em dash bug, testimonial and services images
4. **Pre-Launch Gate + Launch** — Tracking verification, visual sign-off, activate campaigns

Do not publish campaigns until both pre-launch gate checks pass (Section 5).

## 2. Creative Production Plan

### 2.1 Toolchain

| Step | Tool |
|---|---|
| Avatar image generation | ChatGPT (DALL-E) — prompted to spec below |
| Video production | HeyGen — custom avatar imported from generated image |
| Captions | HeyGen built-in caption tool |
| On-screen text / hook overlays | HeyGen |
| Static ad images | ChatGPT (DALL-E) — lifestyle imagery, brand overlay in Canva |

### 2.2 Avatar Brief

**Archetype:** Relatable Family Man with light advisor credibility

**Character description:**
- Late 30s to mid-40s
- Clean, put-together but not corporate
- Open-collar casual shirt or smart casual polo — no tie, no full suit
- Warm, neutral home or home-office background
- Direct eye contact, calm and natural delivery
- Helpful advisor-led tone — not selling, guiding
- Not flashy, not "finance bro," not overly polished
- Looks like a responsible homeowner or parent who has been through this thought process and wants to help others

**ChatGPT image prompt (starting point — refine until correct):**
> "Photorealistic headshot of a man in his early-to-mid 40s, approachable and trustworthy, wearing a casual open-collar shirt or smart polo in neutral tones. Warm, slightly soft lighting. Clean neutral home or home-office background. Direct, calm eye contact. Professional but not corporate. High-resolution portrait, chest-up framing. No tie, no blazer. Natural expression."

**HeyGen setup:**
- Import generated image as custom avatar
- Record in English, natural conversational pace, no teleprompter stiffness
- Engel Financial Group name or logo visible in lower third within first 3 seconds of every video

### 2.3 Deliverables

| Asset | Format | Dimensions | Notes |
|---|---|---|---|
| Video master | 9:16 | 1080×1920 | Reels + Stories — master for all angles |
| Video feed | 4:5 | 1080×1350 | Feed adapted — NOT a lazy crop, reframed head-and-shoulders |
| Static feed | 4:5 | 1080×1350 | Simple: one hook, short support line, CTA, brand |

**Per angle (Angles 1–4):** 3 assets each = **12 assets total for Week 1 launch**

**Angle 5 (Retargeting):** 1× 9:16 video only, 10–15 seconds, produced after Day 7 warm pool check

### 2.4 Production Sequence

1. Generate avatar image in ChatGPT → iterate until character matches brief
2. Import avatar into HeyGen, set up custom avatar
3. Produce Angle 1 complete: 9:16 video → 4:5 video → 4:5 static
4. Review Angle 1: avatar quality, captions, safe zones, hook readability, CTA placement
5. Lock the style — same avatar, same brand treatment used for all remaining angles
6. Produce Angle 2, then Angle 3, then Angle 4 in priority order
7. Angle 5 retargeting produced separately after Day 7 warm pool check

### 2.5 Video Requirements (All Cold Traffic)

1. Hook spoken AND on screen within first 2 seconds
2. Captions on every spoken word (HeyGen auto-captions)
3. Engel Financial Group name or logo visible within first 3 seconds (lower third)
4. Agent follow-up spoken in final CTA: "A licensed insurance agent from Engel Financial Group will follow up with your options."
5. CTA spoken and on screen in final 3 seconds
6. **Safe zones (9:16):** No critical text in bottom 250px, top 150px, or within 50px of left/right edges
7. **4:5 adaptation:** Reframe avatar to head-and-shoulders, reduce on-screen text density if needed — hook and CTA must remain fully readable
8. Length: 18–30 seconds cold traffic, 10–15 seconds retargeting only
9. Use "licensed insurance agent" — not "licensed advisor"

### 2.6 Static Ad Requirements

- One dominant hook line (large type)
- One short support line (optional, small)
- One CTA button
- Engel Financial Group logo + "Licensed Insurance Agent Follow-Up"
- Avatar-led brand feel — not generic stock imagery
- Color: navy base, warm gold accent, clean white text
- No body copy inside the image — longer explanation lives in the primary text

## 6. Pre-Launch Gate

Both gates must pass before any campaign is activated.

### Gate 1 — Tracking Verification

1. Add `META_TEST_EVENT_CODE` to Vercel env vars temporarily
2. Redeploy Vercel
3. Complete full wizard + OTP on `/lp/life-insurance` in incognito (no ad blockers)
4. Verify in Meta Test Events tab:
   - PageView ✅
   - ViewContent ✅
   - Lead ✅
   - CompleteRegistration Browser ✅
   - CompleteRegistration Server ✅ (matching event IDs — deduplication confirmed)
5. Verify UTM fields captured in Supabase lead record
6. **Delete `META_TEST_EVENT_CODE` from Vercel and redeploy** — never leave active in production

### Gate 2 — Visual Sign-Off

- Logo updated and confirmed on all pages ✅
- Em dash bug resolved ✅
- Testimonial headshots in place ✅
- Services images in place ✅
- Andrew has reviewed site on mobile ✅

### Launch

Once both gates pass:
1. Activate Campaign 1 in Ads Manager
2. Activate Campaign 2 in Ads Manager
3. Monitor Events Manager for first 24 hours
4. Check warm pool size at Day 7–10 — launch retargeting only if pool exceeds 1,000 people
